# ReportLogic & LogicJudge (ACL 2026 Main)

This repository hosts the **data, code, and evaluation pipeline** for our paper:

> **ReportLogic: Evaluating Logical Quality in Deep Research Reports**

## Overview

The repository includes:

- **ReportLogic** — a human-annotated benchmark for evaluating logical quality in long-form analytical reports.
- **LogicJudge** — a lightweight, rubric-aligned judge model trained to approximate expert logical judgments.
- **Evaluation scripts** — reproducing the evaluation, ablation, and robustness analyses reported in the paper.
